# Navbar Layouts

A collection of two responsive navbar mini projects built using HTML and CSS. Each project demonstrates a different approach to responsive navigation — including a top navigation bar for a landing page and a collapsible sidebar layout.


## Projects

### Responsive Landing Navbar

A modern landing page with a collapsible top navigation menu and a full-width hero section.

*Features:*
- Collapsible (hamburger) top navigation bar
- Fully responsive design for mobile, tablet, and desktop
- Clean UI with centered hero content


###  Sidebar Navigation Layout

A responsive layout featuring a dark-themed sidebar with collapsible navigation links.

*Features:*
- Collapsible left sidebar with smooth toggle
- Dark UI theme with clear section links (Gallery, Events, Feedback)
- Layout adjusts for smaller screens

## Technologies Used

- HTML5
- CSS3
- Responsive Design
- Flexbox
